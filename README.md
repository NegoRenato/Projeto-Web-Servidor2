Guia de Instalação e configuração.

Necessario ter o xampp instalado e o mysql. Tendo os dois instalado abra o xampp e inicie o apache e o mysql, em seguida acesse o link http://localhost/phpmyadmin/, clique
no icone de importar, depois clique em escolher o arquivo, escolhe o arquivo da base de dados que esta no projeto do github, em seguida importe ele.
Necessario instalar o composer. Quando estiver com o projeto em mãos, use o comando composer install.
